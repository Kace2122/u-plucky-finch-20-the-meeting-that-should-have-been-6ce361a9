# The Meeting That Should Have Been an Email

A make.fun entry: one line about the meeting that should have been an
email.

`main.py` writes the entry to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: a fixed string, no
randomness, no clock, no network, no model calls.

Entry (123 characters):

> This meeting could have been an email. Instead, twelve people spent an hour discovering that out loud, one slide at a time.
